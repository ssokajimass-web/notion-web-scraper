# 📚 統合Webスクレイピング ＆ Notion自動転記ツール

指定したWebサイトの全記事走破、検索キーワード/人物名の徹底調査、名言サイト全体の全名言を自動でスクレイピングし、**すべて同一のNotionデータベースへ美しく統合保存**するツールです。

ブラウザで操作できる **Web操作画面 (Streamlit)** と、コマンド1発で実行できる **CLI** の両方に対応しています。

---

## 🌟 主な機能と特徴

### 1. 🌐 サイト全記事モード (完全網羅・上限なし対応)
- **本当に全記事を取得**: `sitemap.xml` / `sitemap_index.xml` を自動解析し、さらに各ページの「次へ」「ページネーション（`/page/2/`等）」「月別アーカイブ」を再帰的に巡回。
- 広告・ヘッダー・フッター・ナビゲーションを自動除去し、「純粋な本文」だけを抽出。
- `limit=0` を指定することで、サイト内の全記事が尽きるまで完全走破可能。

### 2. 🔍 ネット検索モード (徹底調査 Deep Search)
- **50件の壁を撤廃**: 100件、300件、500件など好きな上限を指定可能。
- **徹底調査モード**: 単一クエリだけでなく、人物名やキーワードから「経歴・生涯」「思想・哲学」「インタビュー・発言」「代表作・論文」「評価・解説」などの派生複合クエリを自動生成。
- ネット上のあらゆる重要ページを多角的に検索し、重複を排除しながら何百件もの本文を根こそぎNotionへ集約。

### 3. 💬 名言サイトモード (サイト丸ごと全名言収集)
- **サイト内の全名言を1つずつ分解**: 指定された名言サイトのトップや一覧URLから、サイト内の「全人物リンク」「全カテゴリ」「全ページネーション（1〜最終ページ）」を丸ごとクローリング。
- サイト内に存在する何千件もの名言を、1つずつ個別のNotionレコード（格言・発言者・解説・出典URL）として登録。
- 名言テキストのハッシュ判定により、重複掲載も自動排除。

### 4. 🗂️ すべて同一の1つのNotionデータベースに統合
- 3つのモードをバラバラのDBではなく、**1つのNotionデータベース**に集約保存。
- 「種別」プロパティ（サイト記事 / 検索調査 / 名言・格言）で自動分類されるため、Notion上でフィルターやタブビューを作るだけで快適に一元管理できます。
- 1ブロック2,000文字のNotion制限も自動判定し、長文記事を段落ごとに綺麗に分割して登録。

## 📊 おすすめのNotionデータベース設計

Notion側で1つデータベースを作成し、以下のプロパティを作っておくと自動で認識されます（※名前列があれば他がなくても最低限保存できます）：

| プロパティ名 | Notionでのプロパティ種類 | 自動格納される内容 |
|---|---|---|
| **名前** または **Title** | `タイトル (Title)` | 記事タイトル、または「発言者: 名言」 |
| **種別** または **Type** | `セレクト (Select)` | 「サイト記事」「検索調査」「名言・格言」 |
| **人物** または **著者** | `テキスト` または `セレクト` | 発言者名、検索人物名、記事著者 |
| **URL** | `URL` | 記事や名言の参照元URL |
| **検索クエリ** | `テキスト (Rich Text)` | 検索モード時の検索キーワード |
| **要約** | `テキスト (Rich Text)` | 記事の要約や検索スニペット、名言の解説 |
| **本文** | `(ページ本文)` | 2000文字ずつ自動分割されたクリーンな全本文 |

## 🚀 クイックスタート

### 1. 依存ライブラリのインストール
```bash
pip install -r requirements.txt
```

### 2. Notion API の初期設定
1. [Notion Developers](https://www.notion.so/my-integrations) で「**新しいインテグレーション**」を作成し、**シークレット**（`ntn_...`）を取得します。
2. Notion上で転記先の統合データベースを作成します。
3. データベースページの右上「**…**」メニュー →「**コネクトの追加**」から、作成したインテグレーションを追加します。
4. データベースURLの32桁のIDをコピーし、`.env` に設定します。
   ```bash
   cp .env.example .env
   ```

## 💻 使い方

### 方法A: ブラウザ画面 (Web UI) で操作する 【おすすめ】

直感的なブラウザ画面で、プログレスバーを見ながらワンクリックで操作できます。

```bash
streamlit run app.py
```
- 左サイドバーでNotion APIキーとデータベースIDを入力して「設定を保存」。
- 各タブから「サイト全記事（完全走破）」「ネット検索（徹底調査）」「名言サイト（サイト丸ごと）」を選んで実行。
- 「プレビューモード」をONにすれば、Notionに送らず画面上で抽出結果を確認可能。

---

### 方法B: コマンドライン (CLI) で操作する

#### 1. サイト全記事モード (完全走破)
```bash
# サイト内の全記事を上限なしで走破してNotionへ登録
python cli.py --mode site --target "https://example.com/blog" --limit 0

# 上限50件で画面確認のみ（dry-run）
python cli.py --mode site --target "https://example.com/blog" --limit 50 --dry-run
```

#### 2. ネット検索モード (徹底調査 Deep Search)
```bash
# 人物について派生キーワードを自動展開し、100件の本文を徹底収集
python cli.py --mode search --target "スティーブ・ジョブズ" --limit 100 --deep

# テーマについて通常検索で上位30件をNotionへ登録
python cli.py --mode search --target "生成AI 最新動向" --limit 30
```

#### 3. 名言サイトモード (サイト丸ごと全名言収集)
```bash
# 名言サイト内の全人物・全カテゴリから全名言を丸ごと1件ずつNotionへ登録
python cli.py --mode quotes --target "https://iyashitour.com/meigen" --limit 0

# 50件だけ取得して画面確認（dry-run）
python cli.py --mode quotes --target "https://iyashitour.com/meigen" --limit 50 --dry-run
```
